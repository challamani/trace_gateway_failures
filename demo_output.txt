## 3. Get Pod Logs Request (Example)

Request:
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "get_pod_logs",
    "arguments": {
      "namespaces": ["default", "kube-system"],
      "deployments": ["nginx", "coredns"],
      "tail_lines": 100
    }
  }
}

Expected Response Format:
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "=== Pod Logs Analysis for Gateway Failure Tracing ===\n\nNamespace: default\n...[pod logs]..."
      }
    ]
  }
}

## Use Cases

### 1. Trace Ingress to Backend Flow
Check logs across ingress controller, API gateway, and backend services:
```json
{
  "namespaces": ["ingress-nginx", "api-gateway", "backend"],
  "deployments": ["nginx-ingress", "gateway", "user-service"],
  "tail_lines": 500
}
```

### 2. Debug Crashed Pods
Get logs from previous terminated containers:
```json
{
  "namespaces": ["production"],
  "deployments": ["failing-app"],
  "previous": true,
  "tail_lines": 1000
}
```

### 3. Multi-Namespace Analysis
Examine logs across entire infrastructure:
```json
{
  "namespaces": ["default", "kube-system", "monitoring", "apps"],
  "tail_lines": 200
}
```
